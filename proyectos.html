Desarrollo web

UniversiConnect

Año: 2024.

Hicimos en equipo un prototipo para pedir tutorías, reservar aulas y participar en foros de asignaturas. Tenía perfiles de alumnos, profesores y administradores, y funcionaba en nuestro ordenador.

Yo me encargué de diseñar la base de datos y conectarla con la aplicación. Por ejemplo, cuando un alumno se registraba o pedía una tutoría, la información quedaba guardada. Aprendí a organizar los datos y hacer que la web pudiera utilizarlos.

  • HTML
  • Python
  • Flask
  • MySQL

Ingeniería de datos

Exploración de datos astronómicos de Gaia

Año: 2025.

El gráfico relaciona el color de las estrellas con su magnitud absoluta. Los puntos se agrupan por tipo espectral, y cada tipo aparece identificado en la leyenda.

En este trabajo individual descargué datos de estrellas del catálogo Gaia, los limpié y añadí información de otras fuentes mediante web scraping. Después los guardé en MySQL para hacer consultas y gráficos.

Aprendí a conectar Python con MySQL y a preparar datos de distintas fuentes. Con los gráficos pude explorar la distancia, el color y el brillo de las estrellas.

  • Python
  • SQL
  • MySQL
  • pandas
  • NumPy
  • Matplotlib
  • Astroquery
  • Astropy

Aprendizaje automático

Análisis y predicción de diabetes

Año: 2026.

El árbol va dividiendo los datos según variables de salud, como la medicación para el colesterol, la hipertensión y la edad, hasta llegar a una clasificación.

En este trabajo individual utilicé datos públicos de salud para probar modelos que predijeran la presencia de diabetes. Primero importé y limpié los datos, los exploré con gráficos y después comparé varios modelos.

Aprendí a preparar los datos y comparar los resultados de los modelos. También trabajé con el desequilibrio entre personas con y sin diabetes, y probé técnicas para agrupar los datos y entender mejor las predicciones.

  • Python
  • pandas
  • NumPy
  • Matplotlib
  • seaborn
  • scikit-learn
